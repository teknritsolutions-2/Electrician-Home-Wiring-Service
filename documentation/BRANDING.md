# Ohmivra — Home Electrical Care

The user authorized replacing the descriptive project title with a distinct brand and adopting the existing favicon artwork as the main identity.

## Name

**Ohmivra** is a coined name inspired by the electrical unit “ohm.” The service descriptor is **Home Electrical Care**. The name is used in headers, footers, page titles, accessible home-link names, copyright, social site-name metadata and enquiry downloads. `assets/js/config.js` stores the name and descriptor for JavaScript-generated content.
