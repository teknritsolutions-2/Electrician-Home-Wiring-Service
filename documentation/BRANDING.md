# Cirqavo

The user authorized replacing the descriptive project title with a distinct brand and adopting the existing favicon artwork as the main identity.

## Name

**Cirqavo** is a modern invented name selected after the user requested a replacement in that style. The wordmark is displayed alone, with no subtitle. The name is used in headers, footers, page titles, accessible home-link names, copyright, social site-name metadata and enquiry downloads. `assets/js/config.js` stores the name for JavaScript-generated content.

## One shared mark

`assets/images/circuit-socket-v2.svg` is the canonical socket/junction symbol. Header and footer images reference that same file used by the favicon. The artwork, colors and proportions are identical in light mode, dark mode and RTL; it is not mirrored.

The `logo-light.svg` and `logo-dark.svg` exports deliberately contain identical copies of this two-color artwork, so neither can drift back to the previous connector mark. The 16px/32px favicon PNGs remain unchanged because the approved favicon artwork was retained.

Repository and hosting paths remain `Electrician-Home-Wiring-Service` to preserve the published URL and internal links. The public-facing brand is Cirqavo.
